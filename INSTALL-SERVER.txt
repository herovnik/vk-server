УСТАНОВКА СЕРВЕРА VK-TURN PROXY (хост сервера, Docker)
======================================================
Схема: ПК -> звонки ВК (белый список) -> 151.243.177.158:56000
       -> WireGuard (внутри docker-сети) -> интернет

ФАЙЛЫ
-----
docker-compose.yml — два сервиса: vk_turn (v1.8.3) + vk_wg (2.13.0)
wg0.conf           — серверный WireGuard (ключи уже вписаны)
server-linux-amd64 — запасной бинарник (без Docker), sha256:
  dfe4c9602d6cc21da0f8c5fc289b75ecfcc7e4862d53a7c7aced37e2a115c42e

ВАЖНО: ваш docker-compose не трогается вообще. Это ОТДЕЛЬНЫЙ проект
Docker Compose (-p vkturn) — свои контейнеры, своя сеть. Caddy,
Hermes, браузеры и VS Code не затрагиваются.

ШАГ 1. ЗАПУСК
-------------
cd ~/.hermes/vk-turn        # на хосте; в контейнере это /opt/data/vk-turn
docker compose -p vkturn up -d

ШАГ 2. ПРОВЕРКА
---------------
docker compose -p vkturn ps       # оба контейнера: running
docker logs vk_turn --tail 5      # ожидаем: Listening
docker exec vk_wg wg show         # интерфейс wg0 + peer (PresharedKey есть)

ШАГ 3. ФАЙРВОЛ (если используется)
----------------------------------
sudo ufw allow 56000/udp          # только если ufw активен
# Голый Hostkey без фаервола — шаг пропустить, Docker сам сделает DNAT.
# Наружу торчит ТОЛЬКО UDP 56000. Порт 51820 специально не проброшен.

ШАГ 4. ЖИВАЯ ПРОВЕРКА (после подключения клиента с ПК)
------------------------------------------------------
sudo tcpdump -i any udp port 56000 -c 5
# Увидите пакеты с адресов диапазона 155.212.192.0/20 (TURN-серверы ВК) —
# значит релей работает.

ОСТАНОВКА / УДАЛЕНИЕ
--------------------
docker compose -p vkturn stop     # остановить (конфиги остаются)
docker compose -p vkturn down     # удалить контейнеры и сеть (wg0.conf остаётся)

ЕСЛИ ОШИБКА
-----------
| Симптом                                   | Решение                        |
|-------------------------------------------|--------------------------------|
| vk_wg: «operation not permitted» на tun   | Модуль tun: sudo modprobe tun  |
| vk_turn перезапускается циклически        | docker logs vk_turn — обычно   |
|                                           | неверный CONNECT_ADDR          |
| Порт 56000 занят                          | docker ps --format '{{.Names}} |
|                                           | {{.Ports}}' — найти, кто занял |
